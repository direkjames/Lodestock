# Security

If you find a security problem in Lodestock (for example a way to duplicate items or money, to run commands, or to get hold of a server's Discord webhook address), please **do not open a public issue**.

Report it privately with GitHub's [private vulnerability reporting](https://github.com/direkjames/Lodestock/security/advisories/new) (the "Security" tab of the repository, then "Report a vulnerability"). Include the Lodestock and server versions, and the steps to reproduce it.

You will get an answer within a few days. Once a fix is released, the problem is described in the changelog, and you are credited if you want to be.

Only the latest release is supported with fixes.
